You'll see a warning the first time you open BlockMD.

The installers aren't code-signed yet. On Windows, choose More info → Run anyway. On macOS, right-click BlockMD in Applications and choose Open. You only need to do this once.

Make BlockMD open .md files when you double-click them

Windows doesn't let installers change your default apps. Right-click any .md file, choose Open with → Choose another app → BlockMD, then select Always.

Does the Windows installer need an internet connection?

BlockMD needs Microsoft Edge WebView2. It's already installed on Windows 11 and most Windows 10 PCs. If it's missing, the installer downloads it, so the first install needs a connection.
